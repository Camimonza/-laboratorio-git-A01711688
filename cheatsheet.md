## Comandos

* pwd : Ruta de a carpeta actual, dónde estás parado.
* ls : lista de archivos y carpetas dentro de la carpeta donde ya estás.
* cd : ca,biar dirección, cambiar de archivo
* cd .. : sube de nivel en el directorio
* cd ../.. : sube dos niveles
* cd ~ te lleva a home
* mkdir <nombre> : crea una carpeta nueva en la dirección actual
* mkdir -p <ruta/subarpeta> Crea una estructura nueva de carpetas y subcarpetas 
* clear : limpia el texto de la terminal sin borrar archivos ni historial
* git init : Coniverte una carpeta en un repositorio
* git status : Te dice el estado actual del repositorio
* git add : guarda el update del archivo
* git add : actuaiza todo
* git commit -m '..' : deja un comentario sobre el update
* git restore : ctrl z de lo último hecho hasta el último commit. 
* git restore --staged : saca al archivo de la zona de preparación
* git commit --amend -m '...' : modifica y reescribe el último commit realizado
* git diff : compara el archivo actual con lo que cambiaste después del git add
* git diff : muestra lo que sí se ba a incluir en la confirmación
* git pull : trae todas las nuevas actualizaciones
* git push : sube toda las nuevas actualizaciones
